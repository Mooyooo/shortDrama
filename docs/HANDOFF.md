# Handoff — 2026-09-29

Started from a Claude Code session in the socialManager repo; continue here.

## Where things stand

- Expo project created with `create-expo-app` (default template, Expo SDK 57, expo-router, TypeScript). Routes live in `src/app/`.
- `expo-video` installed (`npx expo install expo-video`); its config plugin was added to `app.json`. These changes are **not committed yet**.
- GitHub: https://github.com/Mooyooo/shortDrama (private), branch `master`. Pushes over HTTPS using the macOS Keychain login, like socialManager; `http.postBuffer` is raised in this repo's git config because the first push failed with HTTP 400. `gh` is installed but not logged in.
- Expo account created (Google sign-in; use `npx expo login --browser`). The feed runs on the user's iPhone in Expo Go.
- This Mac has only Xcode Command Line Tools, not full Xcode. Test on a real iPhone with Expo Go (`npx expo start`), and build with EAS in the cloud.
- **Phase 1 in progress:** four tabs (For You, Discover, My List, Profile) with SF Symbol icons. For You is a vertical paging `FlatList` feed ([src/app/index.tsx](../src/app/index.tsx), [src/components/feed-item.tsx](../src/components/feed-item.tsx)); only the visible item plays, its neighbours stay mounted and paused so they preload; tap to pause; pauses when the tab loses focus. Sample data in [src/data/catalog.ts](../src/data/catalog.ts) uses public HLS test streams (Google's `gtv-videos-bucket` sample MP4s now return 403). Discover, My List and Profile are placeholders. Tabs live in `src/app/(tabs)/` under a root Stack; "Watch full series" in the feed opens [src/app/series/[id].tsx](../src/app/series/[id].tsx) (muted trailer as poster, tags, synopsis, episode grid with locks past the free episodes). Episodes don't open anything yet.
- CI: [.github/workflows/ci.yml](../.github/workflows/ci.yml) runs lint and typecheck on every push.
- ESLint was installed by the first `npx expo lint` run (`eslint.config.js`, `eslint`, `eslint-config-expo`). Typecheck, lint, `expo-doctor` and an iOS export all pass. Not yet tried on a real iPhone.
- `npx tsc --noEmit` needs `expo-env.d.ts`, which is gitignored and generated by `npx expo start`. CI must generate it (for example with `npx expo customize tsconfig.json`, or by creating it with `/// <reference types="expo/types" />`) before type-checking.
- **Backend decisions (2026-09-29):** own content, English only, only our team uploads; Node/Express + Postgres on socialManager's servers with separate `shortdrama` databases; Cloudflare Stream for video + an R2 bucket for images; one monorepo here (`apps/mobile`, `apps/api`, `apps/admin`, `packages/shared`). Servers, database, Cloudflare and deploy details: [docs/INFRA.md](INFRA.md). Design docs: [Content Pipeline](https://claude.ai/code/artifact/8f2a7069-7db2-4fef-893e-59eb6f42512b), [System Architecture](https://claude.ai/code/artifact/f130be47-bed7-427c-b9fa-a1f281f991b3).
- The full plan is in [docs/PLAN.md](PLAN.md), mirrored from the live Claude Doc linked at its top.
